# \## Работа с репозиторием

# 

# 1\. Создать или выбрать задачу в Issues.

# 2\. Создать ветку от актуальной `main`: `feature/<модуль>-<что>`.

# 3\. Внести изменения и проверить их работу.

# 4\. Открыть pull request в `main`.

# 5\. Указать в PR, что изменилось, как это проверить и какой issue он закрывает.

# 6\. Получить ревью другого участника.

# 7\. Тимлид выполняет слияние.
