# Диплом любой ценой

2D-экшен с видом сверху (в духе Soul Knight). Студент проходит «сессию»
по трём предметам в трёх корпусах. Командный проект по «Технологиям программирования».

## Запуск

    pip install -r requirements.txt
    python main.py

Python 3.12+, pygame-ce 2.5.8.

## Управление

- Движение: WASD
- Стрельба: левая кнопка мыши (направление к курсору)
- Esc: выход в меню

## Уровни

1. Печерка (английский, снаряд shoot)
2. Родионова (программирование, двоичный код)
3. Львовка (математика, формулы)

Финал: красный диплом, если ни разу не умер, синий, если умирал.
